# 공용 보상 획득 연출

모든 재화·아이템 받기에 같은 연출을 쓴다: 미션, 우편, 상점 구매, 방치 보상, 보스 클리어, 출석 등.
시안: `Plan/mockups/review/reward_get_sequence.png`. 좌표는 360×640 논리 크기(720×1280에서는 ×2), 연출 가운데 높이 y=300.
필드에서 몬스터가 떨어뜨리는 작은 획득은 팝업 없이 ④(날아가기)만 쓴다.

## 화면 구성
| 요소 | 부품 | 위치 | 크기 |
|---|---|---|---|
| 화면 어둡게 | 검은 판 알파 0.7 | 전체 | |
| 빛줄기 | boss_intro_rays (알파 0.8, 천천히 회전 1바퀴 6초) | 가운데 (180, 300) | 280×280 |
| 제목 판 + "보상 획득" 13pt | win_title | 가운데, 보상 칸 위 30 | 142×38 |
| 보상 칸 | 등급 색 테두리 칸 (인벤토리 아이템 칸과 공용) + 아이콘 | 가운데 정렬 | 1개 64×64, 여러 개 52×52, 간격 10 |
| 수량 | 11pt #E6C27A, 어두운 글자 테두리 | 칸 아래 4 | |
| 안내 | "화면을 누르면 닫혀요" 9pt #C2A888 | 칸 아래 | |

- 칸 배치: 한 줄 최대 5개. 6~10개는 두 줄(줄 간격 80). 10개를 넘으면 그 아래 스크롤.
- 재화 칸 테두리 색: 골드 = 전설 금색, 보석 = 신화 빨강, Hood_Exp = 고급 초록(임시). 장비는 등급 색.

## 움직임
| 시간 | 움직임 |
|---|---|
| 0.0초 | 화면 어둡게(0.15초), 빛줄기·제목 나타남 |
| 0.15초~ | 보상 칸이 왼쪽부터 0.12초 간격으로 튀어나옴: 크기 0 → 1.18 → 1.0 (0.2초) |
| 다 나온 뒤 | 화면 아무 곳이나 누르면 닫힘. 다 나오기 전에 누르면 남은 칸을 한 번에 보여 줌 |
| 닫을 때 (0.5초) | 재화는 위쪽 해당 재화 칸으로, 아이템은 하단 인벤토리 탭으로 곡선을 그리며 날아감 (아이콘 3~4개로 나눠서, 0.05초 간격) |
| 도착 | 재화 칸이 잠깐 빛나고 숫자가 올라감(0.3초 동안 세기). 재화 칸 왼쪽에 "+5,000"이 떠올랐다 사라짐. 인벤토리 탭은 빛나고 알림 점 |
