# 보스 클리어 연출 (보상 포함, 한 장면)

시안: `Plan/mockups/review/boss_clear_sequence.png`. 좌표는 360×640 논리 크기(720×1280에서는 ×2).
클리어 창은 따로 띄우지 않는다. 문장과 보상을 한 장면에서 보여 주고 자동으로 닫힌다. 공용 보상 팝업(LAYOUT_reward.md)도 띄우지 않는다.

## 화면 구성
| 요소 | 부품 | 위치 | 크기 |
|---|---|---|---|
| 화면 어둡게 | 검은 판 #140C06 알파 0.55 | 전체 | |
| 빛줄기 | boss_intro_rays (회전 1바퀴 6초) | (30, 110) | 300×300 |
| 가로 띠 | clear_band (9-slice 위아래 18px) | (0, 213) | 360×34 |
| 문장 | clear_emblem (VICTORY 글자 포함 연출용) | (76, 163) | 208×139 |
| 반짝임 | fx_sparkle 5~7개 (크기·투명도 랜덤) | 문장·보상 둘레 | 9~18 |
| 보상 칸 | 등급 칸 + 아이콘, 가운데 정렬 | y=330, 간격 14 | 60×60 |
| └ 수량 | 11pt #E6C27A, 어두운 글자 테두리 | 칸 아래 4 | |
| └ "첫 클리어" 꼬리표 (첫 클리어 보상 칸만) | tag_first + 9pt #FFF3DC | 칸 위 -14, 칸보다 양옆 4 넓게 | (칸 폭+8)×16 |
| 안내 | "화면을 누르면 바로 받아요" 9pt #FFF3DC | 가운데, y=428 | |
| 자동 닫힘 바 | bar_track + bar_fill(#E6C27A), 2초 동안 채워짐 | (130, 444) | 100×6 |

- 칸 순서: 첫 클리어 보상(있을 때만) → 클리어 보상. 칸이 많으면 간격을 줄여 한 줄에 맞추고, 5개를 넘으면 칸을 52로 줄인다.

## 부품
- clear_emblem, clear_band, fx_sparkle, tag_first, boss_intro_rays, bar_track, bar_fill, 재화 아이콘
- `clear_panel`은 이 방식에서는 쓰지 않는다(다른 결과 창에 쓸 수 있어 남겨 둠).
- 아직 없는 것: 등급별 보상 칸(인벤토리·공용 보상과 공용, 기획 등급 확정 후)

기획 확인 필요: 첫 클리어 보상 내용(차트 First_Clear = 보석 100), 클리어 보상 구성, 자동 닫힘 시간(시안 2초).
