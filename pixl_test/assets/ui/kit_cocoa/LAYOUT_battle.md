## 재화 숫자 표시 (2026-11-28 추가)
골드가 커지면 판 밖으로 넘쳐 보석 판에 가려진다. 숫자를 줄여 쓰고 골드 판을 넓힌다.
- 숫자: 1만부터 단위로 줄인다. 이미 있는 단위 변환(GameUtill의 만·억·조…)을 쓴다. 유효 숫자 4자리, 소수는 최대 2자리: `9,999` → `1.23만` → `12.34만` → `246.6만` → `1,234만` → `1.23억`. 단위 포함 최대 6글자.
- 골드 판: (232, 8) 56×22 → **(214, 8) 74×22** (왼쪽으로 넓힘). icon_gold (218, 11). 숫자 10pt, **오른쪽 정렬, 오른쪽 끝 x=282**.
- 보석 판은 그대로 (293, 8) 61×22. 보석도 같은 규칙으로 줄인다.
- 다른 창(성장 비용, 보상 수량, 방치 보상 등)의 큰 숫자도 같은 표기.
