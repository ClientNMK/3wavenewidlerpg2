# 전투 화면 배치 (보스 도전 포함)

시안: `Plan/mockups/review/boss_challenge_states.png`. 부품: `parts/`, 글꼴 DNFBitBitv2.
좌표는 왼쪽 위 기준 (x, y), 360×640 논리 크기. **720×1280에서는 모두 ×2**.
고정: 상단 HUD·스테이지 바·보스 버튼 = 위, 사이드 버튼 = 오른쪽, 스킬 칸·하단 탭 = 아래.

## 상단 왼쪽·가운데만 85% (확정)
아래 표의 좌표·크기는 100% 기준이다. 표대로 배치한 뒤, 묶음 2개만 Scale 0.85로 줄인다.
비교 시안: `Plan/mockups/review/hud_scale_top_85.png` (오른쪽이 적용 모습).

| 묶음 | 들어가는 것 | Scale | Pivot (360×640 기준) |
|---|---|---|---|
| 왼쪽 위 | 초상화, 레벨, 이름, 경험치 바 | 0.85 | 왼쪽 위 (0, 0) |
| 가운데 위 | 스테이지 바, 보스 도전 버튼, 자동 도전, 안내 한 줄, 보스전 남은 시간·포기 | 0.85 | 가운데 위 (180, 0) |

- 그대로 100%: 재화, 자동 전투, 사이드 버튼(우편·랭킹·설정·줌), 스킬 칸, 하단 탭 바, 보스 등장 연출, 실패 알림 판.
