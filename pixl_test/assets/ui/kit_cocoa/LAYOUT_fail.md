# 실패 연출 (보스 실패, 쓰러짐)

시안: `Plan/mockups/review/fail_sequence.png`. 좌표는 360×640 논리 크기(720×1280에서는 ×2).
보스 등장 연출(LAYOUT_battle.md 맨 아래)과 같은 틀을 어둡고 차갑게 바꾼 것이다.

## A. 보스 실패 (시간 초과·쓰러짐·포기)
| 시간 | 움직임 |
|---|---|
| 0.0초 | 전투 멈춤. 화면 전체에 어두운 판(#1A1620, 알파 0.6)을 덮고, 그 위에 `fail_vignette`(가장자리 빨강)를 화면 크기로. 셰이더 없이 이미지 두 장으로 처리 |
| 0.1초 | 가로 띠 `fail_band` 펼쳐짐, 그 위로 `fail_emblem`이 위에서 떨어지며 두 번 흔들림(좌우 3도) |
| 0.5초 | 문장 아래에 이유 한 줄: "시간 초과" / "쓰러졌어요" / "포기했어요" (13pt #E2765E) |
| 1.2초 | 문장이 위로 올라가 작아지고(0.8배), 아래에 결과 판이 나타남 |
| 확인 | 결과 판 닫힘 → 스테이지로 돌아와 0/10, 자동 도전 꺼짐 (알림 판 없음) |

| 요소 | 부품 | 위치 | 크기 |
|---|---|---|---|
| 가로 띠 | fail_band (9-slice 위아래 18px) | (0, 263) | 360×34 |
| 문장 (처음) | fail_emblem | (84, 221) | 192×128 |
| 문장 (결과 판 위) | fail_emblem | (104, 90) | 152×101 |
| 결과 판 | fail_panel (9-slice 사방 48px, 둥근 모서리·장식 포함) | (24, 190) | 312×300 |
| └ 보스 이름 / 이유·남은 체력 | 11pt #FFF3DC / 10pt #E2765E | 판 위쪽 가운데 | |
| └ 보스 체력 바 | bar_track + bar_fill(#C84B3A) | (60, 242) | 240×8 |
| └ "이렇게 강해질 수 있어요" | 10pt #E6C27A | 가운데 | |
| └ 바로가기 줄 3개 | fail_row + hud_round + 아이콘 + 이동(btn_main) | (36, 294)부터 44 간격 | 288×38 |
| └ 확인 | hud_pill + "확인" 12pt | (104, 434) | 152×32 |

바로가기 줄은 지금 할 수 있는 성장을 보여 준다(예: 골드 강화, 후드 먹이기, 장비). 할 수 있는 강화가 있는 줄에 알림 점.

## B. 일반 스테이지에서 쓰러짐
가벼운 연출. 문장 없이 판 하나, 자동으로 다시 시작한다.

| 요소 | 부품 | 위치 | 크기 |
|---|---|---|---|
| 화면 | 어두운 판 + fail_vignette (A와 같음), HUD는 그대로 보임 | 전체 | |
| 판 | win_row | (70, 236) | 220×78 |
| └ "쓰러졌어요" | 14pt #E2765E | 가운데 | |
| └ 안내 한 줄 | 9pt #FFF3DC | 가운데 | |
| └ 다시 시작 바 + "3초 뒤 다시 시작" | bar_track + bar_fill(#E6C27A) / 8pt #C2A888 | (100, 292) | 160×8 |

기획 확인 필요: 일반 스테이지에서 쓰러지면 처치 수가 초기화되는지, 다시 시작까지 몇 초인지.
