## 구현 확인 (2026-11-28, 도전 탭 스크린샷 기준) — 고쳐 주세요
1. **보스 그림이 없다.** 띠에 배경만 있음. 보스 idle 스프라이트를 띠 오른쪽에, 위로 30 넘치게 넣는다('보스 띠' 줄).
2. **단계 줄에 첫 클리어 보상이 없다.** 모든 줄에 "첫 클리어" 9pt (120, 15) + icon_gem (176, 12) + "+수량" 10pt (196, 14). 잠긴 줄은 보석 알파 0.5. 깬 줄은 오른쪽에 "받음" + icon_check.
3. **"최고 0단계"는 쓰지 않는다.** 아직 안 깼으면 "아직 안 깸 · 단계마다 강해져요".
4. **도전 버튼은 (60, 540)에 고정.** 단계 목록 영역이 버튼 위(y=530)까지 채우고 그 안에서 스크롤. 지금은 버튼이 목록 바로 밑에 붙어 아래가 비어 있음.
5. 단계 수 확인: 차트 1001은 5단계인데 4단계까지만 나옴.

### 2차 확인 (같은 날) — 1·2·4 고쳐짐, 남은 것
6. **보스가 한 마리면 얼굴 줄을 숨긴다.** 지금 빈 동그라미 + "도전 전"만 떠 있음. 보여 줄 때도 동그라미 안에 보스 얼굴이 들어가야 한다(빈 원 금지).
- 보스 얼굴은 스프라이트를 잘라 쓰지 말고 캡처 이미지를 쓴다: `ArtSource/monsters/<보스>/portrait/portrait_<보스>.png` (지금 monster_dungeon_2001만). 44×44 원형 마스크 안에 꽉 채움, Point 필터.
7. **띠의 보스가 너무 크다.** 폭 130, 띠 위로 30만 넘치고 아래는 띠 끝에서 자른다. 지금은 띠 위로 70쯤 솟고 창이 띠 아래로 삐져나옴.
