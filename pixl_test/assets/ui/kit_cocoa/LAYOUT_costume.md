## 크기 맞추기 (캐릭터·후드 모두, 고정 좌표 금지)
그림마다 몸 크기가 달라서(소녀 약 58×85, 후드 정령 약 38×41) 스프라이트에서 투명하지 않은 영역(보이는 몸)을 기준으로 맞춘다.
1. idle 첫 프레임의 보이는 영역 (l, t, r, b)를 구한다(텍스처 Read/Write 켜기, 또는 미리 재서 저장).
2. 배율 = 목표 몸 높이 ÷ (b - t). 미리보기 100, 의상 칸 46.
3. 몸 아래 가운데 ((l + r) / 2, b)가 목표 점에 오게 둔다. 미리보기 (240, 332), 칸 안 (29, 50).
