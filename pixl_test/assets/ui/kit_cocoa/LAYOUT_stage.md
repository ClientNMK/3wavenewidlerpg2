# 스테이지 이동

시안: `Plan/mockups/review/stage_move.png` (지금 데이터 월드 1·2 각 5개 / 50개일 때 스크롤 예). 좌표는 360×640 논리 크기(720×1280에서는 ×2).
깬 스테이지와 최고 스테이지로만 이동한다. 못 간 스테이지·월드는 잠김.

## 스테이지가 늘어날 때 (같은 창, 스크롤)
- 칸 목록은 처음부터 세로 스크롤 영역으로 만든다. 줄이 늘면 영역 높이가 62씩 늘고, 최대 200까지 늘어난 뒤부터 스크롤한다. 팝업도 같은 만큼 커지고 화면 가운데 정렬을 유지한다(50개 예시는 (24, 96) 312×460).
- 한 월드에 10개가 넘으면 10개마다 구분 줄: 1px #E6C27A 알파 0.35 가운데에 "1-21 ~ 30" 9pt #C2A888(글자 뒤는 창 색으로 가림), 그 아래 20에서 칸 시작.
- 창을 열면 지금 있는 칸이 보이게 자동 스크롤. 위아래 끝 22px은 창 색으로 흐려지고, 오른쪽(x=326)에 3px 스크롤 막대(바닥 #E6C27A 알파 0.18, 손잡이 #E6C27A).
- 월드가 4개 이상이면 월드 탭도 가로 스크롤(탭 폭 88 고정).
