# 글자 스타일 (모든 창·HUD 공통)

작성 2026-11-28. 견본: `Plan/mockups/review/text_style.png`.
글꼴: DNFBitBitv2 SDF 하나. LAYOUT 문서의 크기(pt)는 360×640 기준이라 **720×1280에서는 ×2**.
LAYOUT 문서에 적힌 색 코드는 아래 스타일 중 하나다. 표에 없는 색은 쓰지 않는다(등급 색 제외).

## TMP 재질 3개
| 재질 | 파일 | 설정 | 언제 |
|---|---|---|---|
| 기본 | DNFBitBitv2 SDF (기본 재질) | 테두리 없음 | 불투명 창 판 위(win_panel, win_popup, win_row, win_chip, 버튼, 꼬리표) |
| 테두리 | DNFBitBitv2 SDF Outline.mat (이미 있음) | Outline Width 0.3, Outline Color #2A1A14, Underlay 끔 | 그림·필드·반투명 HUD 위 (아래 '테두리 쓰는 곳'), 일반 데미지 |
| 치명타 테두리 | DNFBitBitv2 SDF Crit.mat (새로) | Outline Width 0.35, Outline Color #961E14, Underlay 끔 | 치명타 데미지만 |

- LAYOUT 문서의 "어두운 글자 테두리", "어두운 글자 그림자"는 모두 **테두리** 재질이다.
- 재질은 이 3개만 쓴다. 색은 재질이 아니라 TMP Vertex Color로 바꾼다(재질 안 늘리기).

## 테두리 쓰는 곳 (재질: 테두리)
- 필드 위에 바로 놓이는 글: 보스 도전 아래 안내 한 줄, 일반 데미지 숫자(치명타는 치명타 테두리), 보스 이름 컷인, 클리어·실패 문구
- 그림 위 글: 던전 카드·소환 무대·의상 미리보기·월드 그림 띠 위 이름과 숫자
- 진행 바 위에 겹치는 숫자: "320/500", "120/300"
- 반투명 HUD(80%) 위 글: 스테이지 바 글자, 재화 숫자, 사냥 기록 숫자
- 그 밖의 불투명 창 안 글자는 모두 기본 재질

## 크기
- LAYOUT 문서의 pt를 그대로 쓴다. 쓰는 크기는 7, 8, 9, 10, 11, 12, 13, 15, 20, 24pt뿐이다.
- 7pt는 꼬리표 안 짧은 글자에만. 문장은 8pt 이상.
- 칸보다 긴 글(이름 등)은 TMP Auto Size로 최소 8pt까지 줄인다. 줄바꿈 대신 줄인다.

## 적용 순서 (개발자)
1. 기본·테두리·치명타 테두리 재질 3개만 남기고 정리
2. TMP 프리셋(또는 프리팹) 8개를 위 스타일 이름으로 만든다
3. 지금 화면의 글자를 LAYOUT 문서 색 코드 → 위 표 스타일로 바꾼다
