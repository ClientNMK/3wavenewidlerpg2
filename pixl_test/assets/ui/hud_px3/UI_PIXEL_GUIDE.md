# 도트 UI 제작 가이드 — 소라게 후드 소녀 (B안)

작성: 2026-11-27. 상태: **초안 (부품 목록 확인 전)**.
부품을 한 장에 몰아 뽑지 않고 **한 번에 하나씩** 만들기 위한 기준 문서. 예전 Codex용 `gpt_pack/UI_ART_GUIDE.md`의 도트 판.

## 1. 방향
- UI도 **도트**. 캐릭터·몬스터와 같은 픽셀 굵기로 보이게 한다.
- 재료: 코코아 갈색 판, 크림 조개 테, 금테 한 줄, 노란 주 버튼, 청록 보석 포인트.
- 화면 구성은 팀 레퍼런스 화면(얇은 재화 판, 판 없는 사이드 아이콘, 스테이지 띠, 슬롯 5칸, 하단 탭)을 따른다. 색·모양은 따라가지 않는다.
- 전투 중 보이는 것은 얇고 작게. 장식은 양끝에만.

기준 예시: `review/hud_caseB_other_x3.png`, 부품 예시: `review/parts_caseB_x6.png`

## 2. 팔레트 (16색 고정, PixelLab `palette`에 그대로 넣음)
| 용도 | 색 |
|---|---|
| 외곽선 | #2A1A14 |
| 갈색 판 (어두움→밝음) | #402820 #583830 #7A5040 #A87850 |
| 크림 (그늘, 밝음) | #D8C0A8 #F8E0C8 |
| 금 (어두움, 기본, 밝음) | #B87828 #EDB948 #FFF1B8 |

색 의미: 노랑 = 누를 것, 청록 = 재화·포인트, 산호 빨강 = 닫기·알림, 갈색 = 바탕, 바랜 크림 = 비활성.

## 3. 모든 부품 공통 규칙
1. **한 번 생성에 부품 하나** (상태 묶음 normal/pressed/disabled는 한 장 허용).
2. 투명 배경, 글자·숫자 없음. 글자는 엔진 폰트(DNFBitBitv2)로 얹는다.
3. 외곽선은 #2A1A14 **1px**, 사방 같은 굵기.
4. 빛은 위에서. 재질마다 2~3단계 명암, 그라데이션·디더링 없음.
5. 늘리는 부품(판·버튼·바·패널)은 **가운데가 완전히 똑같은 열**이어야 한다. 무늬·얼룩·보석은 양끝 고정 구간에만.
6. 아이콘은 판과 **따로** 만든다 (판 위에 엔진에서 얹음).
7. 반투명 픽셀 없음 (알파 0 또는 255).

## 4. 크기 기준 (개발 확인 필요)
- 1배 = 캐릭터 그림 1픽셀과 같은 굵기. 아래 표의 크기는 모두 1배.
- 제안: 화면 논리 크기 240×427 → 기준 캔버스 720×1280에서 **3배**로 표시. 정수 배율만 쓴다.
- 납품 파일은 1배 PNG. Unity: Filter Point, Compression None, 늘리는 부품은 Sliced.

## 5. 만드는 방법 (부품 하나당)
1. PixelLab `create_ui_asset`, 256×256, `palette` = 2장 16색, `pieces`에 그 부품 하나만 크게 배치 (목표 크기의 4배 위치값 = 출력에서 2배). 비용 10회.
2. 결과는 2배로 그려져 나오므로 2×2 → 1칸으로 줄인다 (`work/compose_cases.ps1`의 `Get-Half`).
3. 외곽선 1px로 다시 두르고 여백을 자른다 (`work/split_caseB.ps1`의 `Set-Outline`, `Save-Trim`).
4. 손질: 가운데 열 통일, 좌우 대칭, 얼룩 제거. 9-slice 값 측정.
5. 캐릭터 옆 3배 미리보기로 확인받고 → 확정본만 `ArtSource/ui/`로.

단순한 부품(진행바, 알림 점, + 버튼)은 생성하지 않고 직접 찍는다 (`../hud_hand/work/Px.cs`, 비용 0).
