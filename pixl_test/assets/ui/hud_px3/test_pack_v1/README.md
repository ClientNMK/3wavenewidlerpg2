## Unity 임포트
- Texture Type: Sprite (2D and UI), Sprite Mode: Single
- **Filter Mode: Point**, Compression: None, Mip Maps 끔
- **Pixels Per Unit: 50** (Canvas Reference PPU 100 기준 → 부품 1픽셀 = 캔버스 2단위). 캔버스 기준 720×1280에서 부품을 2배로 보여 주는 설정
- 늘리는 부품: Sprite Editor에서 위 Border 입력 → Image Type = Sliced, Fill Center 켬
- 늘리지 않는 부품: Image Type = Simple, Set Native Size

## 확인할 것
1. **픽셀이 고른가**: 가로 720·1080·1440 화면은 정수 배율이라 깨끗해야 한다. 가로 1170처럼 정수가 아닌 배율에서 선 굵기가 들쭉날쭉한지 본다 (가장 큰 위험).
2. **늘려도 번지지 않는가**: 창·줄·버튼을 위 크기로 늘렸을 때 모서리와 금테가 유지되는지.
3. **글자가 들어가는가**: "1194자6847해 > 1195자2268해"처럼 긴 값이 줄 안에서 강화 버튼과 겹치지 않는지.
4. **기기에서 읽히는가**: 에디터 말고 실제 폰 화면에서.
5. **캐릭터와 어울리는가**: 뒤에 전투 화면이 보이는 상태에서.
