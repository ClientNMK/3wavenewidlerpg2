## 공통 원칙 (우리 창이 별로였던 이유와 대응)
1. **틀은 얇고 평평하게, 디테일은 아이콘에.** 세 게임 모두 판·줄 테두리가 1~2px 선 수준이고 거의 민무늬. 화려한 건 아이콘과 버튼뿐. → 우리 list_row(3배 굵은 금테·리벳)는 틀이 너무 무거웠음.
2. **명도 3단계.** 바탕(가장 어두움) → 줄 판(한 단계 밝음) → 버튼(가장 밝은 강조 1색). → 우리 창은 바탕·줄·탭이 같은 진갈색이라 뭉쳤음.
3. **강조색은 하나.** 슬레이어 = 초록 +버튼, 레츠고 = 노랑, 미카 = 거의 무채색 + 빨간 알림점. 여러 색을 섞지 않음.
4. **창은 화면 아래 절반을 꽉 채우는 판.** 위 절반은 전투가 계속 보임. 떠 있는 작은 창보다 화면 폭 전체 바텀 패널이 기본.
5. **UI 픽셀은 캐릭터보다 가늘다.** 도트 게임이어도 UI 선은 화면 해상도 기준 얇은 선 + 도트 폰트. 굵은 도트 틀은 버튼·아이콘 같은 작은 부품에만.

## 우리 쪽 적용안
- 줄 판: 진갈색 민무늬 + 1px 밝은 윗선 정도로 단순화. 리벳·금테 제거.
- 창 바탕: 줄보다 한 단계 어둡게 (#2A1A14 ~ #402820), 줄은 #583830.
- 강조: 노란 강화 버튼 하나만. 탭 선택은 밝은 윗줄로만 표시.
- 굵기: 틀은 2배 이하, 아이콘은 지금처럼 도트.
