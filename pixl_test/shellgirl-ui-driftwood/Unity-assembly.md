# 표류목과 항해 수첩 · 메인 UI

preview.png는 기존 배경과 캐릭터에 새 판을 합성한 전투 HUD / 정령의 둥지 시안입니다. 각 화면의 논리 크기는 360×640입니다. 기존 720×1280 Canvas에서는 배치 크기와 글자 크기를 약 2배로 시작합니다.

## 새로 생성한 투명 PNG

| 파일 | 용도 |
| --- | --- |
| stage_wood | 재화 상단 바, 스테이지 제목, 둥지 머리판 |
| sailcloth_card | 부화 바로가기, 알 부화와 펫 카드 |
| button_coral | 보스 도전처럼 현재 화면의 주요 행동 |
| button_teal | 자동 전투, 둥지 행동, 선택된 하단 탭 |
| progress_track | 웨이브와 부화 진행바의 빈 홈 |
| progress_fill | 홈 안쪽의 청록 채움 |

reused 폴더에는 미리보기에 사용한 기존 초상화, 자개 프레임 및 아이콘 8종이 들어 있습니다. 전투 배경, 소녀, 후드, 몬스터는 기존 프로젝트 자산을 그대로 사용합니다.

## Unity 배치

- Sprite (2D and UI), Sprite Mode Single, Alpha Is Transparency를 적용합니다. 이번 일러스트 UI는 Bilinear, 기존 픽셀 아트는 Point로 시작합니다.
- 문구는 TextMeshProUGUI로 별도 배치합니다. 밝은 카드엔 검갈색, 나무/색 버튼엔 아이보리 글자를 사용합니다. 나무의 왼쪽 따개비와 오른쪽 옹이, 천 카드 오른쪽의 끈 자리를 피해 텍스트 여백을 잡습니다.
- 나무와 천 가장자리는 장식이 있는 고정 비율 시안입니다. 샘플과 크게 다른 가로세로 비율이 필요하면 좌·중앙·우 영역의 실제 크기를 잡아 분리한 뒤 늘립니다.
- 진행바는 트랙 위를 채움 Image로 덮습니다. Type = Filled, Method = Horizontal, Origin = Left입니다. 기존 진행 수치를 fillAmount에 연결합니다.
- 자개 프레임 안에 기존 초상화를 별도 Image로 넣고, 재화와 나머지 버튼의 장식 밀도는 낮게 유지합니다.

제작 방식은 내장 이미지 생성입니다. 첨부 자료는 무광 색면과 종이·목재 재질의 참고로 사용했습니다. 원본 시트와 생성 프롬프트를 동봉했습니다.
