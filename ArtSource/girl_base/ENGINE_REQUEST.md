이펙트는 캐릭터 칸 밖으로 나가므로 **캐릭터와 별도 스프라이트**로 그리고, 왼쪽을 볼 때 캐릭터와 함께 반전합니다.

### 타격감 (평타 기준, attack3는 괄호 값)
1. 히트스톱: 맞는 순간 캐릭터·몬스터·이펙트 전부 **0.1초 (0.12초)** 정지
2. 피격 번쩍임: 정지 동안 + 0.07초, 몬스터를 **검은 실루엣**으로 (SpriteRenderer 색 덮기 셰이더, 이미지 추가 없음)
3. 밀림: 몬스터 **5px (6px)** 뒤로 → 0.25초에 걸쳐 원위치
4. 화면 흔들림: **2px (3px)**, 정지 시간 + 0.15초 동안 줄어듦

## 4. 스킬: 사라졌다가 적 뒤에서 나타나 가로 베기 (vanish → backstab)

데모: `animations/backstab/skill_vanish_backstab_demo_x2.gif`

1. 스킬 시작 → `vanish` 재생 (0.84초). 마지막 프레임은 비어 있음 = 캐릭터 안 보임. **0.30초에 `effects/vanish_burst` 이펙트 1회** (3장 표 참고, 데모 `effects/vanish_burst/vanish_fx_demo_x3.gif`)
2. 사라진 상태로 **0.2초 정도** 대기 (이 동안 판정 무시/무적 처리는 기획 판단)
3. 캐릭터 위치를 **목표 몬스터의 뒤쪽 바로 옆**으로 순간이동. 방향은 **몬스터를 바라보게** 함 (몬스터가 캐릭터 왼쪽이면 flipX — 보통 이 경우)
   - 데모 기준: 몬스터 중심에서 캐릭터 pivot까지 약 42px
4. 바로 `backstab` 재생 (0.77초). 처음 0.28초 동안 점이 모이며 나타나는 효과가 그림에 들어 있음 → **appear는 재생하지 않음**
5. **휘두르는 순간 = frame_004 (0.28초)** 에 타격 판정 + 타격 불꽃(몬스터 등쪽) + 히트스톱 등 타격감 (평타·attack3 수치 참고). 4~7번은 팔을 뻗은 자세 유지
6. 베기 이펙트: 다른 공격처럼 캐릭터 앞쪽을 베는 이펙트를 캐릭터와 같은 방향(flipX 같이)으로 0.28초 근처에 재생. ⚠️ 예전 "뒤로 찌르기"용으로 만든 `effects/skill_xslash/backstab/xslash_backstab`(flipX 반대 설정)은 **지금 동작과 방향이 안 맞음** — 기본 X베기(`effects/skill_xslash/xslash.png`)나 평타 베기를 쓰거나 아트에 다시 요청
7. 끝나면 idle (마지막 프레임이 idle 자세)

참고:
- vanish는 hurt frame_005(맞은 자세)에서 시작합니다 (2026-11-27 idle에서 교체). 다른 공격 중간 자세에서 바로 흩어져야 하면 아트에 "어느 동작 몇 번 프레임"을 알려주세요 (스크립트로 바로 만듦, 비용 없음)
- (선택) 셰이더로 하고 싶다면: 디졸브 셰이더 + 위로 날아가는 점 파티클로 어떤 프레임에서든 사라지게 만들 수 있습니다. 그 경우 vanish/appear 이미지는 연출 참고용
