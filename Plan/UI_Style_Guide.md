# UI 스타일 가이드 — 어두운 코코아 + 금선

작성: 2026-11-27. 상태: **방향 확정, 부품 제작 전**.
기준 시안: `Plan/mockups/screen_prototype_standalone.html` (HUD 2번 + 창 B). 이 문서와 시안이 다르면 시안이 기준.
이전 가이드(`pixl_test/assets/ui/gpt_pack/UI_ART_GUIDE.md`, `hud_px3/UI_PIXEL_GUIDE.md`)는 이 문서로 대체.

## 1. 한 줄 요약
도트 게임 화면 위에 얹는 **매끈한(도트 아님) UI**. 어두운 반투명 코코아 판, 가는 금선, 크림색 글자. 화려한 금선 문양은 큰 틀 몇 곳에만.

## 2. 원칙
1. **판은 평평하게.** 그라데이션·질감 없음. 판 하나 = 채움 1색 + 금선 1줄.
2. **명도 3단계.** 창 바탕(가장 어두움) → 줄·칸(한 단계 밝음) → 버튼(금색, 가장 밝음).
3. **강조는 금색 하나.** 누르는 것(버튼, 선택된 탭)만 금색으로 채운다.
4. **색은 아이콘에.** 판은 갈색·금색뿐이고, 색은 능력치 아이콘 배지와 진행바에만 쓴다.
5. **장식은 세 곳만.** 스테이지 바, 초상화 틀, 창 제목. 목록 줄·버튼·탭에는 장식 없음.
6. **HUD는 반투명(80%), 창은 불투명(100%).** HUD는 전투가 비쳐 보이고, 창은 글자가 읽히게 완전히 가린다.

## 3. 색
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 금선 | `#E6C27A` | 모든 테두리, 구분선, 장식 선, 선택된 탭 채움 |
| 금 버튼 | `#F2B544` | 주 버튼(강화, 보스 도전), 레벨 표시, 금화 |
| 크림 글자 | `#FFF3DC` | 기본 글자 |
| 흐린 글자 | `#C2A888` | 레벨, 보조 설명, 꺼진 탭 |
| 어두운 글자 | `#2A1A14` | 금색 판 위의 글자, 글자 외곽선 |
| HUD 판 | `rgba(58,34,24,0.8)` | 재화, 이름, 스테이지 바, 사이드 버튼, 스킬 칸 |
| 하단 탭 바 | `rgba(42,26,20,0.88)` | 하단 메뉴 |
| 창 바탕 | `rgb(38,24,19)` (불투명) | 창 |
| 줄·칸 | `rgba(84,54,40,0.75)` | 목록 줄, 창 제목 판 |
| 홈 | `rgba(0,0,0,0.32)` | 수치 칸, 진행바 바닥, 꺼진 탭 |
| 비활성 | `rgba(120,96,80,0.5)` | 누를 수 없는 버튼, 빈 스킬 칸 |
| 오름 초록 | `#9BD65A` | 오르는 수치, 경험치 바, + 버튼 |
| 진행 산호 | `#EE7A5C` | 스테이지 진행바, 선택된 하단 탭 |

능력치 배지 색: 공격 `#FF8A5C`, 체력 `#FF6F7D`, 재생 `#8CCB4F`, 방어 `#6FB6F2`, 관통 `#B58CF0`, 치명 `#FFD34E`. 아이콘 그림은 흰색 채움 + 어두운 선.

## 4. 모양
크기는 화면 **360×640 논리 크기** 기준 (720×1280에서 2배, 1080×1920에서 3배).

| 항목 | 값 |
|---|---|
| 금선 굵기 | 1.5 |
| 알약 판 | 높이 22, 양끝 완전히 둥글게 |
| 둥근 사각 판 | 모서리 10~12 (탭 10, 스킬 칸 11, 목록 줄 12) |
| 창 | 위쪽 모서리 18, 안쪽 4 들어간 곳에 금선 한 줄 더 |
| 버튼 | 알약 모양. 그림자·두께 없음 (금색 채움만으로 구분) |
| 구분선 | 금선 1 + 가운데 마름모 7 |
| 글꼴 | DNFBitBitv2. 제목 11~12, 본문 10~11, 보조 9, 버튼 속 작은 글자 8 |

## 6. 장식 규칙
- 금선 한 색(`#E6C27A`)으로만 그린다. 채움 색은 판 색을 넘지 않는다.
- 위치는 판의 **양끝, 윗변 가운데, 모서리**. 가운데 늘어나는 구간에는 넣지 않는다.
- 참고 이미지: `pixl_test/assets/ui/reference/ref_ornate_*` 5장.
- 시안의 외눈·껍데기 장식은 임시. 중립 금선 문양(소용돌이, 마름모, 별)으로 바꾼다.

## 7. Unity 설정 (제안)
- 부품은 3배(1080 폭 기준)로 내보낸다. 반투명은 이미지에 그대로 넣는다.
- Texture Type: Sprite (2D and UI), Filter Mode: **Bilinear** (도트 아님), Compression: None, sRGB 켬.
- 늘리는 부품은 Sprite Editor Border 지정 후 Image Type = Sliced.
