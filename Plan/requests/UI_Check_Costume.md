## 사용자 답 (2026-11-28)
- 창 위치: 성장 탭 아님. 별도 창으로 두거나, 나중에 장비 탭이 생기면 그 안에 '코스튬'으로 둔다 → 시안은 하단 탭 강조 없이 만듦.
- Costume_Point: 아직 구현 안 됨. 의상마다 포인트를 모아 일정 포인트(50p, 100p…)마다 스탯을 준다 → 시안 ③에 단계 스탯 창 추가 (단계·스탯 값은 가안).

## 시안 구성
- 탭 2개: 캐릭터(소녀) / 후드(정령)
- 탭 아래: 코스튬 포인트 바 (지금 포인트, 다음 단계까지, 다음 스탯). 누르면 단계 스탯 창(③): 다다른 단계는 '적용 중', 다음 단계는 진행 바, 그 뒤는 자물쇠
- 미리보기 왼쪽 아래: 이 의상이 주는 포인트 (+5p)
- 위: 고른 의상을 입은 모습 크게 + 등급·이름
- 가운데: 보유 효과(가지고만 있어도) / 착용 효과(입었을 때만)
- 아래: 의상 칸 5열, 등급 색 테두리, 착용 중은 '착용' 꼬리표, 없는 의상은 검은 그림자 + 자물쇠 + "???"
- 버튼: 착용 / 착용 중

## 정해 주세요
1. 차트에 캐릭터용·후드용 구분 열이 없음 → 종류(Type) 열을 둘지
2. 창 위치: 별도 창이면 어디서 여는지 (사이드 버튼 / 장비 탭 생기기 전까지 임시 입구)
3. 코스튬 포인트: 캐릭터·후드가 함께 쓰는 하나 (사용자 확인). 단계 스탯은 다다르면 '받기'로 받고, 여러 개는 '모두 받기' (사용자 요청, 시안 ③). 단계 포인트·스탯 값 정해 주세요
4. 없는 의상: 그림자 + "???"로 숨길지, 그림과 얻는 곳(상점·이벤트 등)을 보여 줄지
5. 의상 강화·레벨이 있는지 (있으면 칸에 Lv와 강화 버튼 추가)
6. 후드 의상이 후드 진화 단계(hood_001, hood_002…)마다 따로 그려지는지, 한 벌이 모든 단계에 맞는지
