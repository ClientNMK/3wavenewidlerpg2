# 구현 요청 — 후드 레벨업 (코딩 세션)

작성 2026-11-27. 기획 기준은 `Plan/HoodSpirit_Pet_Nest_Design.md`. 화면 배치는 `Plan/requests/UI_Hood_Window.md`와 한 쌍이다.
게임은 **세로형(720×1280)** 이다.

## 1. 한 줄 요약

후드가 몬스터를 포식하면 Hood_Exp(재화 5)를 얻고, 후드 화면에서 후드에게 먹여 레벨을 올린다.

> 2026-11-28 변경: Hood_Exp는 확률 드롭이 아니라 포식으로 얻는다. 일반 포식 = StageChart `Hood_Exp_Value`, 스테이지 보스 마무리 포식 = `Boss_Hood_Exp_Value`. StageChart DropItem은 재화 4로 바뀌었다.

## 2. 이미 된 것 (2026-11-27 코드 확인, 다시 만들지 않는다)

- 드롭: `InGameManager.HandleMonsterDead`에서 StageChart `DropItem_Rate` 확률로 `HoodGoods += DropItem_Value`
- 차트: `HoodData` (HoodChart 구간, `GetCost`, `GetStatValue`)
- 레벨: `Hood.Level`, 스킨은 HoodChart `Resorce`, 포식 체력 비율은 `Hood.PredationHpPer` (`MainCharacter.TryPredation`이 사용)
- 화면: `UIHoodPopup` (스탯 이름 + Lv, 현재 값 > 다음 값, 보유 / 필요, 먹이기 버튼)

## 3. 요청 (기획 확정)

1. **들어가는 곳을 성장 창으로 옮긴다.** 하단 탭은 6개(성장, 인벤토리, 스킬, 미션, 컨텐츠, 상점)로 확정됐고 "후드" 하단 탭은 없다. 후드 화면은 성장 창(`UIGoldUpgradePopup`)의 탭 하나로 넣는다. 탭은 5개다: 강화, 레벨, 후드, 전직, 어빌리티 (확정, 바뀔 수 있음).
2. **화면 구성을 "먹여서 키우는 화면"으로 바꾼다.** 위에서 아래로:
   1. 후드 크게 (Spine idle)
   2. 후드의 한마디 (한 줄)
   3. 후드 레벨
   4. 경험치 바: 보유 Hood_Exp / 다음 레벨에 필요한 Hood_Exp
   5. 효과 줄: 포식 가능 체력 현재 % > 다음 %
   6. 먹이기 버튼
3. **먹이는 것은 Hood_Exp 하나다.** 아이템 목록, 자동 선택은 만들지 않는다.
   - **먹이기 버튼은 한 번에 가진 만큼 전부 먹인다.** 가진 Hood_Exp로 올릴 수 있는 레벨까지 한 번에 올린다(구간이 바뀌면 다음 구간 비용으로 이어서 계산). 수량 선택(×1, ×10, MAX)과 꾹 누르기는 만들지 않는다.
   - 버튼 글자에 오를 레벨 수를 같이 보여 준다. 예: "먹이기 (+3)". 1레벨도 못 올리면 버튼이 눌리지 않는다.
   - 여러 레벨이 오를 때는 경험치 바가 여러 번 차오르고 레벨 숫자가 빠르게 올라가는 연출을 넣는다. 연출 길이는 오른 레벨 수와 상관없이 1초 안쪽으로 한다.
   - 보유 Hood_Exp를 아이콘(`icon_goods_hood_exp`)과 함께 보여 준다.
4. **먹이면 후드가 반응한다.** 화면 속 후드가 `devour` 애니메이션을 한 번 재생하고 idle로 돌아온다. 한마디가 바뀐다.
5. **한마디는 StringChart 키로 읽는다.** 키 이름은 `Hood_Talk_1`부터 차례로 두고 그중 하나를 무작위로 고른다. 문구는 기획에서 StringChart에 넣는다(아직 없음 → 그때까지 키 이름이 그대로 보여도 된다).

## 4. 확인이 필요한 것 (구현 전에 사용자에게 묻기)

- Hood_Exp를 얻었을 때 표시: 처치 기록에 한 줄 추가, 금화처럼 떨어지는 그림. 기획 추천은 둘 다 넣는 것이다(지금은 얻어도 아무 표시가 없다).
## 5. 이번에 하지 않는 것

- 저장 (후드 레벨, Hood_Exp)
- 전직, 후드 스킬, 여러 종류 먹이기
- 차트 수치 조정 (1001 증가량이 레벨당 +0.0001로 작다. 수치 설계 때 다룬다)

## 6. 완료 기준

1. TitleScene에서 Play → 몬스터를 잡으면 Hood_Exp가 쌓인다.
2. 하단 "성장" → 후드 탭에서 후드, 레벨, 경험치 바, 효과, 먹이기 버튼이 보인다.
3. Hood_Exp가 모자라면 먹이기 버튼이 눌리지 않는다.
4. 먹이면 가진 Hood_Exp로 올릴 수 있는 만큼 레벨이 한 번에 오르고, 경험치 바와 효과 수치가 바뀌고, 후드가 `devour`를 재생한다.
5. 레벨 100이 되면 스킨이 HoodChart 다음 구간의 `Resorce`로 바뀐다.
6. 최대 레벨(500)에서는 버튼이 MAX로 바뀐다.
