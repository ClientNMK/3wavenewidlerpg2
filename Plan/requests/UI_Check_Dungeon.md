시안: `Plan/mockups/review/dungeon_tab.png` (① 컨텐츠 탭 카드 목록 ② 단계 고르기 창 ③ 던전 안 HUD)

**답 받음 (2026-11-28)**: 아래 가정 6개 모두 그대로 간다(이름·보상은 지금 가안 유지). 추가: 컨텐츠 창을 탭 2개로 나눈다 — **던전**(티켓 던전 카드 목록) / **도전**(단계 오르기).
- UI가 정한 도전 탭 가안: 차트 1001(5단계·60초)을 도전으로 본다. 티켓 없이 계속 도전, 소탕 없음, 단계마다 첫 클리어 보상(보석). 던전 탭은 1002처럼 티켓 보상 던전. 다르면 알려 주세요.
- 변경 (사용자 제시, 2026-11-28): 던전은 단계 고르기 창 없이, 던전 탭 카드에서 바로 깬 최고 단계 보상·소탕·다음 단계 입장을 보여 준다.

## 시안에서 가정한 것
- 컨텐츠 탭 = 던전 목록. 던전마다 그림 카드 한 장(이름, 단계 수·제한 시간, 최고 단계, 보상 아이콘, 티켓 수, 입장).
- 카드를 누르면 단계 고르기 창: 단계별 보상, 깬 단계 체크, 다음 단계 "도전", 위는 잠김.
- 버튼 두 개: 깬 최고 단계 **소탕**(바로 보상) / 다음 단계 **입장**. 둘 다 티켓 1장.
- 던전 안: 스테이지 바 자리에 보스 체력, 그 아래 남은 시간. 시간이 다 되면 실패, 티켓은 돌려받음.

## 정해 주세요
1. 던전 이름과 각 던전 보상 (차트 1001은 보상 0, 1002는 Reward_Item 7 ×1000)
2. 소탕을 넣을지
3. 실패하면 티켓을 돌려줄지
4. 티켓 충전 방식 (시안: 매일 0시에 2장/1장으로 채움), 광고나 보석으로 더 살 수 있는지
5. 던전이 열리는 조건 (차트에 Open_CharGrade, Open_Awakening_Slot, Recommended_Stage가 있음 — 화면에 무엇을 보여 줄지)
6. 클리어·실패 연출은 보스 클리어·실패 연출(LAYOUT_clear.md, LAYOUT_fail.md)을 그대로 써도 되는지
