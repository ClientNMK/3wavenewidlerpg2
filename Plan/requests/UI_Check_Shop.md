## 소환 — 정해 주세요
1. 소환 종류 탭 (시안: 무기 / 방어구 / 장신구). 장비 부위가 정해져야 함
2. 소환 비용: 티켓(Goods 1001~1003)과 보석, 10회·30회 가격, 30회 할인 여부
3. 광고 무료 소환 하루 횟수 (시안 3번)
4. 소환 레벨(많이 뽑을수록 높은 등급 확률 상승)을 둘지
5. 등급 수와 확률 (시안은 인벤토리 시안의 6등급)
6. 결과 연출: 한 장씩 뒤집기 / 한 번에 공개 (시안은 한 번에 + 높은 등급 빛남)

## 시안 구성
- 탭 3개: 추천 / 보석 / 패키지
- 추천: 기간 한정 패키지 배너(남은 시간, 원래 가격 줄긋기) → 매일 무료(무료 보석, 광고 보석 2/3, 광고 티켓 1/2) → 일일 상점(보석으로 던전 티켓·골드 묶음·Hood_Exp·소환 티켓·꿈 조각 구매, 하루 1번)
- 보석: 6단계 보석 상품, 상품마다 첫 구매 2배

## 정해 주세요
1. 탭 구성 (시안: 추천 / 보석 / 패키지). 소환(뽑기)을 상점에 넣을지, 따로 둘지
2. 매일 무료·광고 보상 내용과 하루 횟수
3. 일일 상점에서 보석으로 파는 것과 가격, 하루 구매 횟수
4. 보석 상품 단계와 가격, 첫 구매 2배를 할지
5. 패키지 종류 (기간 한정, 성장 단계별, 월정액 등)
6. 광고 제거 상품을 넣을지
