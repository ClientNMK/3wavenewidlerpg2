# UI 요청 — 후드 화면 (UI 파트)

작성 2026-11-27. 스타일 기준은 `Plan/UI_Style_Guide.md`(어두운 코코아 + 금선), 부품은 `pixl_test/assets/ui/kit_cocoa/`. 기능은 `Plan/requests/Dev_Hood_LevelUp.md`와 한 쌍이다.

## 1. 한 줄 요약

후드에게 Hood_Exp를 먹여 키우는 화면. 성장 창의 탭 하나로 들어간다. **주인공은 후드**다.

## 2. 전제

- 게임은 **세로형 720×1280** 이다. 크기는 스타일 가이드처럼 360×640 논리 크기로 적는다.
- 참고한 화면(정령에게 아이템을 먹이는 가로형 화면)에서 가져오는 것은 "가운데 큰 정령, 한마디, 경험치 바, 먹이기 버튼"뿐이다. 가로형 배치(왼쪽 능력 목록, 오른쪽 아이템 목록)는 쓰지 않는다.
- 먹이는 것은 Hood_Exp 하나라서 아이템 목록과 자동 선택이 없다.
- 창 틀, 제목, 탭, 닫기는 성장 창(`UIGoldUpgradePopup`)을 그대로 쓴다. 이 요청은 탭 안쪽 내용 영역만 다룬다.

## 3. 배치 (세로 한 줄로 쌓기, 위에서 아래)

| 순서 | 내용 | 설명 |
|---|---|---|
| 1 | 후드 무대 | 후드를 가운데에 크게(도트라서 정수 배율), 발밑에 그림자. 뒤는 홈 색 판. 무대가 비어 보이지 않게 후드가 무대 높이의 대부분을 채운다 |
| 2 | 한마디 | 후드 아래 한 줄. 최대 2줄까지. 가운데 정렬 |
| 3 | 레벨 | "Lv.12" 금색 글자, 가운데 |
| 4 | 경험치 바 | 가로로 길게. **Hood_Exp 아이콘과 "보유 / 필요" 숫자를 붙여서** 바 위에 본문 크기 이상으로. 이 화면에서 가장 중요한 숫자다. 아이콘은 스테이지에서 떨어지는 그림과 같은 것 |
| 5 | 효과 줄 | 목록 줄 하나: 배지 아이콘 + "포식 가능 체력" + 수치 칸 "50% > 50.01%" |
| 6 | 먹이기 버튼 | 금색 주 버튼, 가로로 넓게, 맨 아래. 엄지로 누르는 자리. 한 번 누르면 가진 만큼 전부 먹인다. 글자는 "먹이기 (+3)"처럼 오를 레벨 수를 같이 보여 준다 |

- 누르는 것은 먹이기 버튼 하나뿐이므로 금색 채움은 이 버튼에만 쓴다.
- 장식은 넣지 않는다(장식은 창 제목에 이미 있다). 후드 무대도 민무늬 홈 판이다.

## 4. 부품

**있는 부품으로 조립**

- 후드 무대 뒤 판, 경험치 바 바닥: 홈 색 판 / `bar_track`, `bar_fill`
- 효과 줄: `win_row`, `badge_stat`, `win_chip`
- 먹이기 버튼: `btn_main`, `btn_main_off`

**새로 필요한 부품**

| 파일 | 용도 | 크기(논리) | 비고 |
|---|---|---|---|
| icon_goods_hood_exp | Hood_Exp 재화 아이콘 | 16×16 | GoodsChart Icon 이름과 같게. 금화 아이콘과 한눈에 구분되는 색 |
| icon_predation | 효과 줄 배지 아이콘 (포식) | 18×18 | 다른 능력치 아이콘처럼 흰 채움 + 어두운 선 |
| win_bubble | 한마디 판 | 48×24 | 가로로 늘림. 위쪽 가운데에 후드를 가리키는 꼬리. 꼬리는 늘어나지 않는 구간에 |

- 경험치 바 채움 색은 스타일 가이드의 "오름 초록 `#9BD65A`"를 쓴다.
- 포식 배지 색은 아직 없다. 후드의 청록 계열을 제안한다(확정 아님).

## 5. 상태 (시안에 같이 보여 주기)

1. 기본: Hood_Exp가 충분함 → 버튼 금색
2. 모자람: 버튼 비활성(`btn_main_off`), 바가 덜 참
3. 최대 레벨: 바가 가득, 버튼 글자 "MAX", 효과 줄은 현재 값만

## 6. 아직 안 정한 것

- Hood_Exp의 화면 표시 이름 (기획에서 정한다. 그때까지 시안에는 임시 글자)

정해진 것:
- 성장 창 탭은 5개다: 강화, 레벨, 후드, 전직, 어빌리티 (확정, 바뀔 수 있음)
- 수량 선택(×1, ×10, MAX)은 넣지 않는다(확정). 자리를 비워 둘 필요 없다
- 후드 스킬(레벨에 따라 열리는 능력)을 넣을지 → 넣으면 효과 줄 아래에 줄이 늘어난다

## 7. 받고 싶은 것

1. 720×1280 세로 시안 1장 (상태 3개를 나란히)
2. 방향 확인 뒤 새 부품 3개 (3배 크기 PNG, 글자·숫자 없이)

## 8. 규칙 (기존과 같음)

- 글자·숫자는 이미지에 넣지 않는다. 글자는 문자열 키로 넣는다
- 늘어나는 부품은 9-slice, 가운데는 민무늬
- 없는 부품은 임의로 대체하지 말고 요청한다
