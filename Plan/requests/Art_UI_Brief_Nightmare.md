# 아트·UI 콘셉트 요청 — 「나이트메어」

작성 2026-11-26. 배경·UI 작업자에게 전달하는 분위기 안내서. 세부 기획은 `Plan/HoodSpirit_Pet_Nest_Design.md`의 '스토리' 섹션을 기준으로 한다.

## 1. 한 줄 세계관

깨어나지 못하는 소녀의 꿈속에서, 애착 담요였던 후드 정령이 악몽을 먹어 소녀의 기억을 되찾아 준다.

## 2. 분위기 키워드

- 잠들기 전의 동화책, 밤, 머리맡 무드등
- 무섭기보다는 **"조금 으스스하지만 귀여운"** 꿈
- 꿈 = 따뜻하고 포근함 / 악몽 = 어둡고 기묘함. 두 가지가 한 화면에 같이 있다
- 무거운 이야기(깨어나지 못하는 소녀)는 암시로만 둔다. 화면은 밝고 귀엽게

## 3. 색 방향

| 구분 | 색 | 쓰는 곳 |
|---|---|---|
| 캐릭터 팔레트 (유지) | 크림, 코코아 외곽선 #3A1E1A, 산호, 청록, 금색 | 소녀·후드·몬스터 (이미 확정된 아트) |
| 꿈 (따뜻함) | 크림, 연한 금빛, 무드등 주황 | 빛, 보상, 꿈 친구(펫), 알 |
| 악몽 (어두움) | 짙은 남색~남보라 밤하늘, 검은 그림자 | 배경의 어두운 부분, 악몽 몬스터의 기운 |
| UI (확정: 갈색안) | 갈색 판 + 담요 크림 안쪽 + 코코아 외곽선 #3A1E1A | 판 갈색 값 1~2색(판, 그늘)을 팔레트에 더해 주세요. 모래 배경에 묻히지 않게 바깥 테두리를 두껍게, 넓은 안쪽은 크림으로 |

## 4. 배경 요청

- **월드 1: 꿈속 바닷가** — 처음 바다에 갔다가 길을 잃은 날의 꿈. 해초 슬라임 등 지금 아트가 이 월드에 맞는다. 밤바다, 달빛, 모래 위의 그림자, 멀리 보이는 무드등 같은 빛 한 점.
- 이후 월드(참고용, 지금 그리지 않아도 됨): 어두운 숲(불 꺼진 방) → 장난감 성(혼자 남겨진 놀이방) → 책장 미로(끝나지 않는 동화책) → 더 깊은 꿈.
- 같은 지형에 색감과 소품만 바꿔 월드를 늘릴 수 있게 그려 주면 좋다.

## 5. UI 요청

- 모티프: 동화책 페이지, 담요의 바느질 스티치 테두리, 빨간 리본, 금방울, 별.
- 필요한 부품은 하단 탭과 골드 강화 패널 목업을 기준으로 한다(아래 링크). 기존 남색 hud_kit 부품은 갈색으로 다시 칠할지 새로 만들지 의견을 부탁한다.
- 목업: 하단 탭 + 골드 강화 https://claude.ai/artifact/H8T7SKaa7z9wHsdbyUTNaD / 펫 도감 https://claude.ai/artifact/XxvDxGBgtoBASVCugx6yg9
